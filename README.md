## ⚡ Fitur & Animasi

- **Bingkai Futuristik Foto Profil (`/profil.jpg`):** Terpasang di bagian Hero dengan bracket aksen biru, status ID `PPLG_STUDENT`, dan target grid halus.
- **Partikel Jaringan Biru Bergerak (Hero Network Canvas):** Simulasi canvas 60fps dengan simpul node biru `#0052FF`, garis penghubung `#93C5FD`, dan interaksi dinamis terhadap kursor mouse.
- **Smooth-Scroll Navbar:** Transisi perpindahan halus saat tautan navigasi diklik dengan offset posisi header fixed.
- **Scroll Reveal (Fade-Up Animation):** Menggunakan `IntersectionObserver` untuk menganimasikan kartu dan seksi secara bertahap saat digulir ke viewport.
- **Ambient Depth & Light Mode:** Palet dasar Cool Alabaster (`#F8FAFC`), permukaan Pure White semi-transparan (`backdrop-filter: blur(12px)`), dan rona biru es halus (`#E0F2FE`).
